Girder is available in this repository through its MCP server. When the repository has a Girder graph (a `project.aether` file in the project root), call Girder's `orient` tool before broad file reads or grep: it returns a function's source, callers, callees, tests, and change impact in one call, so you rarely need to open whole files. If Girder reports low confidence, returns an empty or truncated result, or fails, say so plainly and fall back to reading the source yourself; do not guess. Girder's test selection is advisory: the project's own test runner is authoritative.
